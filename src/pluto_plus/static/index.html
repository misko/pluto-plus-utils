08 / Setup

Persistent AD9361/2R2T provisioning

Checking helper

This operation is limited to the immutable canonical tuple. It first verifies the selected serial, USB path, QSPI image, pinned SSH host key, and transmit-safe state. Execution backs up the complete environment, mutes TX, changes only mismatching canonical fields, reboots, and re-attests the same radio.

Transmit safety is mandatory. Both TX gains, buffers, scan elements, DDS scales, and DDS sources must read back in the fail-closed state before any environment write.

Held only in this input. It is never saved or displayed in plan output.
